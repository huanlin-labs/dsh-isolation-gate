# v0.4.0 — 组类型说清楚，会话头就能挂组

> 这一版解决一个真实误解：**在「严格组」里把 E:\ 标成「禁」，不等于"只禁 E"，而是"除了 E 全放、其它一律拒"** —— 正好相反。
> 0.4.0 把这件事写在界面上，并且给了退路。

## 新增

**1. 组类型横幅：白名单模式 / 黑名单模式**

- 「白名单模式」（严格组）：**只放清单里的；没列进组的，一律拒** —— 黄色
- 「黑名单模式」（宽松组）：**只限清单里的；没列进组的，照常放行** —— 绿色
- 编辑区和每张模板卡片上都有，不用记、不用猜

**2. 一键互换类型**

编辑区有「改成宽松组（只禁我选的，其余照常）」/「改成严格组（只放我选的，其余一律拒）」。
**只换「清单外怎么算」，不动清单本身。**

**3. 模板卡片写明谁在用它**

每张模板卡片多一行：`成员 3 个 · 挂在 2 个会话：a1b2c3d4、e5f6g7h8`；没人挂时写「还没有会话挂它」。
——一个组可以被多个会话共用，这件事以前只能在脑子里记。

**4. 会话头部直接挂组**

会话标题栏那个「门禁」小按钮，点开就是当前会话的特别组列表，选中即生效、摘掉即恢复。
**不用重启**：挂/摘都走 `sessionOverrides`，每次工具调用现读状态。

**5. 空清单警示**

严格组清单为空时，界面直接写「**清单为空 ⇒ 这档什么都拒（等同全封）**」——这是最容易一脚踩空的地方。


## 边界（不重复但要看清）

它拦的是**经过 dsh 的工具调用**与**走 `bin/gate.mjs` 的通道**。
`pwsh` 里套一层脚本、别的进程直接读写磁盘、已经注入的上下文——都不在它的射程内。
要更强，得上内核沙箱（Windows ACL / Seatbelt / bwrap），那是另一层的事。
