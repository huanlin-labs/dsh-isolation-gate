# 「门」的语法

一种以**阈限**为核心的设计哲学：不描绘门后之物，只描绘"允许与不允许"之间那道极窄的界面。空间被压缩为几条垂直的缝隙，缝隙的宽窄即权限的宽窄；观者不必读说明，身体先感到"过不去 / 只能看 / 可以通过"。

形式全部来自校准仪器：细如发丝的刻度、重复的短划、成套的对齐线。它们不装饰，只测量。每一个刻度都在同一基线上生成，误差为零——这是必须看上去像被反复校准过数百次的结果，是顶尖匠人用手与眼一点点推出来的精度。

色彩克制到近乎禁欲：近黑的底、骨白的字、一线极淡的冷灰。唯一的"亮"留给那条**允许**的缝隙——它不是装饰性的光，而是秩序中的一个例外，出现得极少，因此每一次出现都有重量。

尺度由张力决定：大面积的空，被三条极窄的竖缝切开。文字是视觉的锚点，不是解释；词只保留三个档位本身，以及作品的名字。所有元素都被压在严格的边距之内，呼吸充足，绝不拥挤——那种留白来自长年的克制，而不是省事。

构图的重心略偏，像一件被长期使用的工具：不居中、不炫耀，却处处对得齐。观众第一眼看到的是秩序，第二眼才看到秩序里那一个被默许的缺口。这正是它要表达的：**规则先于许可，许可才是例外。**

成品必须像博物馆展柜里的校准器具：无一处毛边，无一处随手，所有间距都经过反复推敲。若要在上面再加任何东西，先问：它是否让已有的秩序更清楚？若不能，就不要加。
